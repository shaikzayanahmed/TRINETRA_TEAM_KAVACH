# Git Commit Guidelines

When creating git commits in this repository, always use sequential version tags along with a short descriptive summary as the commit messages:
- Format: `mark0X: <short description of changes>`
- Examples:
  - `mark01: Initial setup and tactical architecture`
  - `mark02: Build complete tactical console UI and routes`
  - `mark03: Live webcam feed with YOLOv8 detection overlay`
  - `mark04: Update landing page copyright year to 2026`
  - `mark05: Add interactive canvas radar and 3D card tilt to landing page`
  - and so on (`mark10: ...`, `mark11: ...`).
