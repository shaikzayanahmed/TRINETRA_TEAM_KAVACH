SOLUTION OVERVIEW

TRINETRA is a tactical perimeter defense software combining Web GIS, Offline Edge AI, and Multi-Sensor Telemetry for zero false-alarm border security.

  • • Tactical Command Web App: Live multi-camera grid, polygon tripwires & instant alert triage.
  • • Edge AI Detection: INT8 YOLOv8 running locally on Jetson (<5ms latency, zero cloud streaming).
  • • Spatial Virtual Tripwires: Vector polygon breach detection transmitting <5KB event JSON.
  • • Evidence Vault & Anonymization: SHA-256 sealed video clips with automated DPDPA face blurring.

  • ✔ Field Mobile App: Cross-platform Flutter app for on-ground Quick Reaction Teams (QRT).
